# 💰 SpendWise

SpendWise is a modern personal finance dashboard built using Streamlit and Plotly.

## Features

- 👩 Multi-user dashboard (Sonika & Puneeth)
- 📈 Expense Trend
- 🍩 Category Breakdown
- 📅 Spending Insights
- 📊 Monthly Comparison
- 🔍 Transaction Explorer
- ☁️ Google Sheets Integration
- 📱 Responsive Dashboard

## Tech Stack

- Streamlit
- Plotly
- Pandas
- Google Sheets

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
